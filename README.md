**SKY WARRIOR: DOMINION** is a 3D aerial flight combat game built with Three.js, TypeScript, React, and Web Audio. Fly the F-22X fighter across a sunset archipelago of volcanic peaks, futuristic coastal towers, and Solaris Airbase in Combat Missions, Endless Survival, or Free Flight.

## Features

- **3D Flight & Cameras**: Smooth pitch, roll, yaw, throttle, afterburner boost, barrel-roll flare evasion, and Chase / Action / Cockpit camera views.
- **Air-to-Air Combat**: Vulcan cannons with predictive lead pip & aim assist, auto-target & missile lock-on, guided missiles, three enemy AI archetypes (Interceptor, Flanker, Gunship), and swept projectile collision.
- **Open World & Audio**: Procedural sunset sky shader, animated ocean sun-glints, multi-island terrain, runway takeoff sequence, aerial checkpoint rings, collectible pods, and synthesized Web Audio jet engine & weapons SFX.
- **Desktop & Touch Controls**: Keyboard + mouse combat controls alongside a responsive virtual flight joystick and mobile HUD.

## Run it

```sh
npm install
npm run build:game
node serve.ts
```

Or run the Vite development server:

```sh
npm run dev
```

## Controls

- **W/S / Arrow Up/Down**: Pitch
- **A/D / Arrow Left/Right**: Roll
- **Q/E**: Rudder Yaw
- **Space / Left Click**: Fire Cannons
- **F / Right Click**: Launch Guided Missile
- **Shift / B**: Afterburner Boost
- **X / V**: Evasive Barrel Roll & Flares
- **T**: Toggle Auto-Target & Assisted Pursuit
- **C**: Cycle Camera (Chase / Action / Cockpit)
- **+/- / Mouse Wheel**: Throttle
- **P / Esc**: Pause · **M**: Mute Audio
